# DR-003 — English is the master language

| Field | Value |
|-------|-------|
| Status | accepted |
| Date | 2026-07-04 |
| Mode | BOOTSTRAP |
| Actor(s) | user (chose "English master, 4 langs co-located") |
| Related | DR-009 (published languages), style |

## Context
The book carries EN/RO/FR/DE. The user chose English as canonical, with the other
three co-located on the page. English is the lingua franca of modern philately.

## Decision
English is the **master**; RO/FR/DE are translations kept in lockstep and flagged
stale when EN changes ([[../style]]). This is independent of how many languages the
*published* book ultimately ships (DR-009).

## Alternatives considered
- Romanian master (subject is Romanian). Recorded as a live option in market
  research; not chosen for the master role.
- Four equal parallel trees. Rejected: duplication, no canonical.

## Consequences
- One language drives edits; translation freshness is trackable.
