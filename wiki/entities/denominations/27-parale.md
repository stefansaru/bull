# 🐃 27 parale — First issue (1858)

The lowest value of the **first *Cap de bour* issue** ([[../issues/issue-bull-1]]),
for the local/printed-matter rate. Catalogued **L.P. 1** (= Kiriac 1 = Michel 1 =
Scott 1 = Yvert 1) ([[../references/compilations/bull-head-catalogue-valuations|valuations]]).

## Design & paper
**Black** printed on **horizontal-laid pale-rose paper**; the aurochs head (*cap de
bour*) with a star between the horns, the value in Cyrillic *СКРИСОРИ / ПОРТО*
([[../census/bull-head-evidence-census|census]], base type — Kiriac 1). A
**tête-bêche** pair variety is recorded (**Kiriac 1a**) — e.g. the 27+27 tête-bêche
cancelled M1 Galați 3/9 1858, a world rarity ([[../census/bull-head-evidence-census]]).
Forgeries are commonly betrayed by **vertical-laid** paper (the genuine is
horizontal-laid) ([[../census/bull-head-evidence-census]]).

## Denomination value
In the 1858 gold-franc parity the four first-issue values map to French centimes:
**27 parale = 25 centimes** (¼ gold franc) (Chiricheș-Pascariu, via
[[../references/compilations/bull-head-catalogue-valuations]]).

## Printing & survival
**Print run 6,016** (188 sheets of 32), of which **3,691 sold** and **2,325**
returned/destroyed — figures identical across Spineanu, Cârjan-Manole and
Chiricheș-Pascariu ([[../references/compilations/bull-head-catalogue-valuations]]).

## Valuation (unused / used)
- Spineanu 1984: **330 000 / 100 000 Lei**
- Cârjan-Manole 2006: **38 000 / 17 000 EUR** (on cover 55 000)
- Chiricheș-Pascariu: **61 498 / 23 481** (unit ⚠)

(currencies not comparable — see [[../references/compilations/bull-head-catalogue-valuations]]).
