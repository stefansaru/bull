# 🐃 108 parale — First issue (1858)

The top value of the **first *Cap de bour* issue** ([[../issues/issue-bull-1]]),
for the heaviest / multiple rate. Catalogued **L.P. 4** (= Kiriac 4 = Michel 4 =
**Scott 3** = Yvert 4) ([[../references/compilations/bull-head-catalogue-valuations|valuations]]).

## Design & paper
**Dark blue** on **horizontal-laid pale-red paper**; a variety on **horizontally
ribbed paper** is also recorded ([[../census/bull-head-evidence-census|census]],
base type — Kiriac 4).

## Denomination value
**108 parale = 1 gold franc** in the 1858 gold-franc parity — the round-franc
value that fixes the whole series (27=¼, 54=½, 81=¾, 108=1 franc)
(Chiricheș-Pascariu, via [[../references/compilations/bull-head-catalogue-valuations]]).

## Printing & survival
**Print run 6,016**, of which **2,574 sold**
([[../references/compilations/bull-head-catalogue-valuations]]).

## Valuation (unused / used)
- Spineanu 1984: **200 000 / 80 000 Lei**
- Cârjan-Manole 2006: **27 000 / 16 000 EUR** (on cover 28 000)
- Chiricheș-Pascariu: **33 545 / 27 954** (unit ⚠)

## Catalogue-order note
**Scott numbers the 108 parale as №3 and the 81 parale as №4** — the reverse of
face-value order; all other systems (Kiriac/Michel/Yvert/L.P.) keep 108 = №4. See
[[81-parale]] ([[../references/compilations/bull-head-catalogue-valuations]]).
