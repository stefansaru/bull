# Should the book stay four-languages-per-page?

Analysis of whether the current **EN/RO/FR/DE 2×2-per-page** design is right, with a
recommendation. Grounded in market/publishing research (2026-07-04). This informs
the still-open **DR-009 (published languages)**; the *master* language is already
English ([[../meta/decisions/DR-003-english-master]]), and the wiki stores all four
regardless, so any edition can be generated ([[../meta/decisions/DR-005-exporter-rebuilds-book]]).

## Bottom line

**The four-up quadrant is very likely the wrong format — and notably it is *not*
what the field's own gold-standard reference uses.** The definitive Bull's Head work,
**Fritz Heimbüchler's *Die Ochsenköpfe der Moldau*, is bilingual German–English**,
three volumes of 400+ pages each [H]. Because our content lives in a structured wiki
that can auto-generate *any* edition, the quadrant pays the full page-real-estate
penalty **and** the full maintenance penalty to solve a bundling problem that cheap
generation has already eliminated.

> **Recommendation:** retire the quadrant. Ship an **English-led master edition** as
> the flagship, and **auto-generate separate, full-page editions** in Romanian,
> German, and French from the wiki. Prefer print-on-demand so no edition needs a
> committed print run.

## Why (the evidence)

1. **Field norm is monolingual; bilingual is the "reach" format; four-up is unheard
   of.** The four standard catalogue houses are each monolingual in their home
   language — **Scott** (EN/US), **Stanley Gibbons** (EN/UK), **Michel** (DE),
   **Yvert & Tellier** (FR) — i.e. the industry solved "many languages" with
   *separate books*, not shared pages [cat].
2. **The definitive Bull's Head reference tops out at bilingual.** Heimbüchler is
   *zweisprachig Deutsch–Englisch*; even two languages already yields 400+ pages per
   volume [H]. The Romanian tradition (Dragomir, Spineanu) publishes in Romanian; the
   classic-French tradition in French — each in its own language, cross-referenced.
3. **The money and the modern lingua franca are English.** Six-figure Bull's Head
   lots sell through Feldman (Geneva), Köhler, Corinphila with **English-first**
   catalogues; famous collections were American/Egyptian/pan-European [mkt]. French
   was historically philately's language (Herpin coined *philatélie*, 1864) but
   **English is now the working default** [upu].
4. **Exhibition eligibility doesn't need four.** FIP recognises EN/FR/DE/RU/ES; for
   FIP *literature* judging a **monolingual** work is fully competitive — and note
   **Romanian isn't an FIP language**, so the quadrant isn't optimising for that
   either [fip].

## The real-estate math

Four languages sharing one A4 page ≈ **¼ page per language** minus gutters/shared
images. Either type/images shrink below comfortable size, or the page count balloons
~3–4×. A "300-page" quadrant is really a ~90-page book printed four times. For a work
whose value is **high-resolution stamp images, plating detail, cancels, and forgery
comparison**, sacrificing three-quarters of every page to redundant text is hostile
to the book's core purpose. And nobody reads more than one quadrant: every serious
reader is fluent in at least one of {their language, English}, so the other three are
dead weight they paid for in price, pages, and image size.

## The single-source insight

Content in a structured wiki is textbook **single-source publishing** (one canonical
source → many outputs, translate-once) [ssp]. That **inverts the usual trade-off**:
normally more editions = more cost, so bundling tempts; here extra editions are
near-free, so bundling only buys a *symbolic* single object at the cost of ruined
layout. You still get the marketing breadth ("available in EN/RO/DE/FR") **without**
the layout cost.

## Options

| Model | Verdict |
|-------|---------|
| (a) English only | Good; matches lingua franca + auction market; but leaves near-free editions on the table. |
| **(b) English master + auto-generated RO/DE/FR editions** | **Best fit** — cheap generation is exactly what makes this dominate. |
| (c) Bilingual EN+RO (one physical keepsake) | Reasonable *iff* a single object is a hard requirement (Heimbüchler's proven half-page model). |
| (d) Keep 4-up quadrant | Weakest — pays every cost single-sourcing was meant to remove; no comparable work does it. |

## Sequencing (recommended)

English master → Romanian (heritage/home) → German & French (scholarship
communities). Wiki stays the single source of truth so corrections propagate once.

## Corroboration from [[market-research]]

A second, independent research pass (market/competitive) reached the **same core
conclusion from a different angle**, with one refinement:

- **Agrees:** retire the 4-up quadrant; no four-language philatelic monograph precedent
  exists; **French adds the least** of the four.
- **Refines:** it ranks **German *above* Romanian** for the *scholarly* core, because
  German is the **incumbent language of Bull's Head scholarship** (Heimbüchler; the
  German expertising world). So the two passes converge on the priority
  **English ≫ German ≈ Romanian ≫ French**, differing only on emphasis:
  - *multilanguage pass* → English master + **separate generated** editions (RO/DE/FR).
  - *market pass* → a **single trilingual EN/DE/RO** object is also viable; drop French
    from print (offer as PDF if demand appears).
- **Net:** because the wiki generates any edition, this is a *print/marketing* choice,
  not an architecture choice. Safe default: **English flagship now; German & Romanian
  next; French only if demand appears.** Still DR-009 (open) — the user decides.

## What this hinges on (check before committing)

1. **Translation quality at acceptable cost.** If dense philatelic terminology can't
   be auto-translated trustworthily without heavy per-language expert review, the
   "nearly free" premise weakens → consider consolidating to **EN + RO** only.
2. **The author's true goal.** If the goal is a **national-heritage art object / gift
   keepsake** rather than a working reference, a *single* physical book is legitimate —
   but even then the answer is **bilingual RO + EN**, not four-up quadrant.

## Honest uncertainties

Exact per-country sales split for this niche isn't publicly quantified (inferred from
auction geography + catalogue markets); "English displaced French" is a well-supported
general trend applied by inference; and no four-language philatelic monograph of
comparable scope could be found to exist — its apparent absence is itself evidence,
weighed as such.
