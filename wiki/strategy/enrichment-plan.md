## Method

Each page: a subagent reads the relevant source page-ranges (from `sources/<id>/text.md`)
+ the existing wiki, synthesises heritage-led English prose, **cites every claim** to
`[[sources/<id>/text]]` + pdf page, labels legends (C-17), marks debates (DR-006), and
lists the images (from `assets/sources/<id>/`) worth using. Present-day rows also run a
cited web search. Status starts `draft`; promoted on review.
