# Glossary

| Term | Meaning |
|------|---------|
| Bundle | `assets/content/`: the generated JSON plus WebP images the app loads. Never edited or committed |
| Unit | One content block of a wiki page, marked `<!-- u:UID kind:… -->`. Kinds: `text`, `quad` (a block that exists in four languages), `table`, `figure` |
| Sidecar | `<page>.i18n.yml`: the translations of a page's units |
| Rights registry | `wiki/assets/rights.yml`: the clearance status of each image |
| Cleared / omit / pending | Rights statuses. Ships / left out by decision / undecided (blocks a release) |
| Width class | compact < 600 dp, medium 600–839 dp, expanded ≥ 840 dp |
| Gate / advisory | A check that blocks / a check that only informs |
| Release verdict | PASS or BLOCKED at the top of the wizard report |
| Baseline (`H-…`) | A Hermes-level requirement every app inherits (Hermes DR-026) |
| Charter (`CH-…`) | The Jini Solutions mission, values, strategy and goals (Hermes Tenant `jini-apps`) |
| Cap de bour | "Aurochs head", the 1858 Moldavian stamps the book is about |
| Parale | The currency unit of the stamp denominations (27, 54, 81, 108 parale) |
