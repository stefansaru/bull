# APP-RDR-001 — Reading view

## Intent
Long-form reading needs a comfortable measure and line height.

## Requirement
Text shall render at a maximum width of 720 dp with 1.5+ line height; tables scroll horizontally; previous/next move through the book.

## Acceptance criteria
- [x] Reading measure and line height
- [x] Previous/next navigation
- [x] Tables readable on phones

Widget tests.
