# Icon set — image-generation prompts

Owner rulings:
- 2026-10-26:
  - **Style:** flat glyph.
  - **Colour:** a single colour, black on white. The app tints the icons, so they follow light/dark and the colour-vision modes.
  - **Scope:** the pictorial symbols of glossary Table 1, the chapter markers, and left/right arrows.
  - **Gum states:** drawn in the philatelic convention (`(*)`, `*`, `**`).
  - **Typographic marks stay text:** ” § ~ ? £.
- 2026-10-27:
  - **Batches:** the 40-icon grid came out poorly, so the set is generated in **4 × 4 batches**.
  - **No vector tracing:** the generator's drawings are used as they are.

Three batches of 16. The 40 agreed icons fill batches 1, 2 and the first half of batch 3. The last 8 cells of batch 3 are **proposals**, symbols the book uses that are not in Table 1; swap any of them out.

Each prompt is self-contained: paste one whole block into the generator. After batch 1 comes out well, attach that image to batches 2 and 3 as a style reference ("match the style of the attached icons exactly").

## Tips

- **If an icon comes out wrong,** regenerate the batch with that icon's line rewritten. Generators do better with concrete shapes ("a circle with a dot") than with names ("a cancellation").
- **If the three batches drift apart in style,** regenerate batches 2 and 3 with batch 1 attached as the reference.
- **Look at each batch small** (about the size of a fingernail on screen) before accepting it. That is the size the app shows them at.
